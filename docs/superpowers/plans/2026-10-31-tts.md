# 選字 TTS（Phonon 31M 串流）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 選取文字按 `Ctrl+Alt+S`，以本地 Phonon 31M 幀級串流將原文唸出；再按一次即停。

**Architecture:** C FFI（Rust 編譯的 `ptts_ffi.dll`）經 P/Invoke 內嵌於單檔 exe；模型權重 embedded resource、首按解壓到 `%LOCALAPPDATA%` 快取；`ptts_speak` 的音訊 callback 直寫 waveOut 佇列播放；TTS 與翻譯兩條流程各自獨立。

**Tech Stack:** .NET 8 WinForms（現有）· P/Invoke（user32 waveWinMM + ptts_ffi）· Rust（僅 CI/本地 script 編譯產物）

**Spec:** `docs/superpowers/specs/2026-10-31-tts-design.md`（同 repo）

## Global Constraints

- .NET 8 / WinForms / `PublishSingleFile` + `SelfContained`（win-x64）；主專案**不新增任何 NuGet 套件**（測試專案維持 xunit）
- TTS 執行期零網路：模型與 dll 皆本地；註解與 UI 字串沿用繁體中文風格
- FFI 介面（`ptts.h`，xn-ptts tag `v0.6.0` 鎖定）：`ptts_new(dir, 0, "en")`、
  `ptts_speak(h, text, cb, user, &result)`、`ptts_last_error`、`ptts_free`；
  音訊 24kHz 單聲道 f32；callback 回 `false` 即停止
- 嵌入資源 LogicalName 前綴 `AITranslator.Tts.`；快取目錄
  `%LOCALAPPDATA%\AITranslator\tts\`（dll 於根層，模型於 `model\`）
- 兩組熱鍵註冊互斥檢查：翻譯/TTS 快捷鍵不可相同（設定驗證擋下）

## Review Focus

| 失敗模式 | 預期行為 | 釘住測試 |
|---|---|---|
| 播放中再按快捷鍵 | 停止出聲（callback false + waveOutReset），狀態回 Ready | Task 6 |

### Task 6: TtsService 狀態機（含 PttsEngine 包裝）

**Files:**

**Interfaces:**
- Produces:

  ```csharp
  public enum TtsState { NotLoaded, Loading, Ready, Speaking, Stopping, Failed }
  public interface IPttsEngine : IDisposable
  {
      string? Load(string modelDir);              // null=成功；非 null=錯誤訊息
      bool Speak(string text, Func<float[], bool> onAudio, out TtsSpeakResult result);
      string? LastError { get; }                  // 對映 ptts_last_error
  }
  public struct TtsSpeakResult { public uint Frames; public double TtfaMs, TotalMs; }
  public class TtsService : IDisposable
  {
      public event Action<TtsState>? StateChanged;   // UI 執行緒上引發（StateChanged 於狀態轉移時同步觸發）
      public TtsState State { get; }
      public string? LastError { get; }
      public TtsService(string modelDir, Func<IPttsEngine> engineFactory, Func<IAudioSink> sinkFactory);
      public void EnsureLoaded();   // NotLoaded/Failed → Loading（Task.Run 載入）；已載完成 → no-op
      public void Toggle(string text);  // Ready→ Speaking（Worker thread）；Speaking/Stopping → Stop()；
                                        // Loading → no-op；NotLoaded/Failed → EnsureLoaded()
      public void Stop();               // stop flag + sink.Stop()；worker 回到 Ready
  }
  ```

  內部：私有 lock 守護狀態；worker thread 跑 `Speak`，callback 內
  `_stopRequested ? false : sink.Write(pcm) 且回 true`；speak 結束（任何原因）→ State=Ready（或 Failed）。
  `Dispose`：stop → join worker（`Join(2000)`）→ engine/sink dispose。

- Consumes: Task 4 的 modelDir（`<cache>\model`）、Task 5 的 sink 與 resolver
